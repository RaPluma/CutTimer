# 它是怎么知道你在画哪一卡的

## 结论先说

**靠「保存事件」，不是靠猜测。**

用 `FileSystemWatcher` 盯住你配置的工作目录，任何 `.clip` 被写入就：

1. 立刻登记（文件可能还在写，先占位）
2. 2 秒轮询等文件稳定后读出真实的基线值
3. 设为当前卡

所以**只登记你真正保存过的文件**，不是目录里的全部 `.clip`。

## 为什么不用「检测当前打开的文档」

这一节把试过的路都记下来，省得以后重复踩。**六条，全部走不通。**

| # | 思路 | 实测结果 |
|---|---|---|
| 1 | 读 CSP 窗口标题 | ❌ 只有「CLIP STUDIO PAINT」，没有任何子窗口带文档名 |
| 2 | 枚举 CSP 的文件句柄 | ❌ **CSP 根本不持有 .clip 句柄**（1264 个句柄里 File 类型 61 个，无一 .clip） |
| 3 | 找临时文件 | ❌ `%TEMP%` 的 GUID 目录、`brief_folder.txt` 里都没有路径 |
| 4 | 找共享内存 | ❌ `CELSYS\interprocess\*` 里只有 GUID 和锁，无文档路径 |
| 5 | UI Automation 读标签页 | ❌ 只暴露 2 个后代元素，**没有任何带名字的元素**（未实现可访问性树） |
| 6 | CSP 插件 API | ❌ **官方只开放滤镜插件**（C++ 图像处理滤镜），不暴露文档 API；也没有 Lua 脚本接口 |

第 2 条尤其反直觉：说明 **CSP 是把整个文档读进内存、编辑期间关闭文件、保存时整体写回**。
这也正好解释了为什么「编辑时不写盘」—— 实测画了 5 分钟，`.clip` 的 mtime 一次都没变。

**结论：CSP 没有提供任何让外部程序得知「当前打开哪个文档」的途径。**

好在原画师会频繁保存（`Ctrl+S` 是肌肉记忆），实际用起来足够跟手。

### 关于「读 CSP 内存」这条路

有人会问：能不能直接扫 CSP 进程内存，把里面存的 `.clip` 路径抠出来？

技术上能做（`ReadProcessMemory` 扫已提交内存区，搜 `.clip` 字符串），但有个**硬伤**：

> CSP 把**所有**打开过的文档路径都留在内存里（标题、最近文件、撤销历史等），
> 扫出来是一堆路径，**分不出哪个是当前活动文档**。

而且 CSP 只在保存时写盘，扫到路径也无法实时拿到作业时间（那个值在内存里，
但位置不固定、格式未公开，没法稳定解析）。所以这条路**投入产出比很差**，没做。

顺带澄清一个常见误解：网上说的「CSP 调色盘插件」其实有两种，都不是内存读取——

| 说法 | 实际是什么 |
|---|---|
| CSP 色板面板 | 内置功能，读写 `.cls` 颜色集文件，**不是插件**，也不碰文档 |
| 第三方取色器 | 独立小工具，采样的是**屏幕像素**（`GetPixel`），不是 CSP 内存 |

## 时间是从 .clip 里读出来的

`.clip` 表面是 CELSYS 的 `CSFCHUNK` 分块容器，但**内部嵌了一个完整的 SQLite 数据库**：

```
CSFCHUNK ……多个块……
  ...
  "SQLite format 3\0"   ← 最后一个块就是一个标准 SQLite 文件
     表 Canvas，列 CanvasWorkTime（单位：毫秒）
```

读取方式：**从文件尾往前**按 8 MB 分块扫，找 `SQLite format 3\0` 这个 magic
（从头找的话要穿过上百 MB 的图像数据）。找到后把这一段切出来写成临时文件，
用只读连接查一次。

### 为什么必须做「差分」

CSP 自己记录的作业时间判定很准 —— 一段時間沒有操作畫布、CSP 在背景運作，
或是操作其他畫布的時間，都会被判为中断、不记录。**但它是所有人累加的**：

> 一卡文件会在 **原画 → 作监 → 第二原画 → 动检** 之间流转，
> 直接读就等于把上游的时间算成你的。

CutTimer 的做法是记下**第一次看到这张卡时的值当基线**，之后只累计增量 ——
上游那部分作为常量偏移被自动抵消。

```
首次看到：  CanvasWorkTime = 85:46:34   → 存为 Baseline，Mine = 0
一小时后：  CanvasWorkTime = 86:02:27   → delta = 15:53，Mine += 15:53
```

所以 `Mine` 才是你自己的时间，`Baseline` 是「接手时已有的」。

## 一个已知的空窗期

刚打开一张卡、还没保存时，工具不知道你切过去了（当前卡会停留在上一张）。
保存一次就同步了。急的话可以在列表里手动点选。

> 添加监视目录**不会**扫描目录里已有的 `.clip`。
> 这是有意的 —— 你只想知道自己画过的卡，不想让几百个旧文件塞满列表。
> 保存过的才会出现。
